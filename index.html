Projet 42 — push_swap
Push Swap est un projet de l'école 42 consistant à trier une pile de nombres entiers en utilisant deux piles (stack_a et stack_b) et un ensemble limité d'opérations (push, swap, rotate, reverse rotate). L'objectif est d'écrire un programme en C qui produit la suite d'instructions la plus courte possible pour trier les données — c'est un exercice d'algorithmique et d'optimisation qui introduit aux concepts de complexité et de tri avancé.
C Algorithmique

Projet 42 — ft_printf()
ft_printf est un projet 42 consistant à recoder la célèbre fonction printf() du C from scratch. Il faut gérer les conversions de formats (%d, %s, %x, %p…) via des fonctions variadic (va_list, va_arg). L'objectif est de comprendre le parsing d'arguments variables, la gestion des types et l'écriture bas niveau sur la sortie standard — une fonction qui sera ensuite réutilisée dans tous les projets suivants.
C Algorithme

Projet 42 — libft
Libft est le tout premier projet de l'école 42 : recoder from scratch une bibliothèque de fonctions standard du C (strlen, memcpy, atoi, split…) sans utiliser la libc. L'objectif est de comprendre en profondeur le fonctionnement des fonctions C de base, de maîtriser la gestion manuelle de la mémoire avec malloc/free, et de produire une bibliothèque personnelle réutilisable dans tous les projets suivants du cursus.
C Algorithme
⚙️
GitHub ↗
Project 42 — get_next_line()
get_next_line est un projet 42 qui consiste à coder une fonction capable de lire une ligne à la fois depuis un file descriptor (fichier, entrée standard…), quel que soit la taille du buffer. Il introduit aux concepts de lecture partielle, de gestion d'un buffer statique entre deux appels, et de manipulation fine de la mémoire en C — un exercice fondamental pour comprendre comment fonctionne la lecture de fichiers au niveau système.
C UNIX Algorithme
